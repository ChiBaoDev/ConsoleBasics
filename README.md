# 
## Chức năng
- Thêm sinh viên.
- Xóa sinh viên.
- Hiển thị danh sách sinh viên.
- Đếm số lượng sinh viên.
- Tìm kiếm sinh viên (không phân biệt chữ hoa/chữ thường).

## Kiến thức áp dụng
- List<string>
- Add()
- Remove()
- Count
- Contains()
- Trim()
- ToLower()
- foreach
- while
- switch-case
- Function

## Cách chạy

```bash
dotnet restore
dotnet run
```

## Menu chương trình

```text
1. Thêm sinh viên
2. Xóa sinh viên
3. Hiển thị danh sách
4. Đếm số lượng sinh viên
5. Tìm kiếm sinh viên
0. Thoát
```
